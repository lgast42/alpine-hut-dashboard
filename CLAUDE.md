# CLAUDE.md

## What this is

Public display layer for alpine hut water monitoring. Frontend only — it
shows numbers, it does not produce them. All data comes from an external
pipeline export; this repository only renders it.

## Data integrity

- Computes nothing itself: no averages, trend lines, or unit conversions.
- Never invents data. Missing values stay visibly empty gaps.
- No methodological detail (thresholds, calibration, derivation logic) in
  code, comments, or docs.
- A set of field names is permanently blocked from ever appearing in this
  repository. The list lives in `blocklist.json` in the project root. That
  file is intentionally not versioned and is generated by the pipeline's
  export script. If it's missing, `npm run check:blocked` aborts.
- Data modules under `src/data/` are generated artefacts — never edit them
  by hand, change the pipeline and re-export instead.

## Setup

A freshly cloned repository is not fully workable until a pipeline export
has been run: `blocklist.json` is required and is not checked in.

## Build & deploy

- `npm run build`
- `npm run check:blocked` (runs automatically as part of `predeploy`)
- `npm run deploy` — deployment is manual, there is no auto-publish on push
